# מי שוטף כלים 🫧

אפליקציית ווב קטנה (נפתחת בטלפון, אפשר להתקין למסך הבית) שעוקבת אחרי מי שוטף כלים אצל אמא ואצל אבא, בין נועה, נווה ואופק.

## איך זה עובד

- **אמא ואבא נספרים בנפרד.** שטיפה אצל אבא לא שווה שטיפה אצל אמא.
- לכל הורה האפליקציה מציעה את **התור הבא**: מי ששטף הכי פחות אצל אותו הורה. בשוויון, מי ששטף שם הכי מזמן, ואז מי שיש לו פחות שטיפות בסך הכול.
- **אירוח:** כשנועה מארחת, זה מחליף את הארוחות של אותו שבוע (ראשון עד שבת): אין תור שטיפה אצל אמא ואבא באותו שבוע, ונרשמת לה שטיפה אחת אצל כל אחד מהם (סבב שלם), אז היא מדולגת כשמגיע תורה. אפשר ללחוץ "בכל זאת לרשום שטיפה" אם בכל זאת היה מה לשטוף.
- **החלפה:** אם מישהו אחר שטף במקום המוצע, לוחצים על שמו, והנקודה הולכת אליו.
- **מי היה בארוחה:** מי שלא היה מסומן ✗ ולא יוצע, ולא נפגע.
- **אין כלים / לא הייתה ארוחה:** נרשם בהיסטוריה ולא נספר לאף אחד.
- אפשר לרשום תאריך אחר, לבטל מיד אחרי רישום, ולמחוק רישום מההיסטוריה.

## הקמה (חד פעמי, כ-10 דקות)

### 1. GitHub Pages
בריפו: Settings → Pages → Source: `Deploy from a branch` → Branch: `main`, תיקייה `/ (root)` → Save.
הכתובת תהיה `https://<שם-המשתמש>.github.io/<שם-הריפו>/`.

### 2. פרויקט Firebase (חינמי)
1. נכנסים ל-https://console.firebase.google.com ויוצרים פרויקט (אפשר בלי Analytics).
2. Build → **Firestore Database** → Create database → מיקום `eur3` או `europe-west` → Production mode.
3. בלשונית **Rules** מדביקים את התוכן של `firestore.rules` ולוחצים Publish.
4. Project settings (גלגל שיניים) → Your apps → האייקון `</>` (Web) → נותנים שם → Register.
5. מעתיקים את אובייקט `firebaseConfig` שמוצג.

### 3. חיבור לאפליקציה
פותחים את `firebase-config.js`, מחליפים את `null` באובייקט שהעתקתם (כמו בדוגמה שבהערה), שומרים ועושים commit. אחרי דקה האפליקציה בכתובת של Pages מסונכרנת בין כל הטלפונים.

### 4. התקנה בטלפון
- אייפון: Safari → שיתוף → Add to Home Screen.
- אנדרואיד: Chrome → תפריט → Install app.

בפעם הראשונה כל אחד בוחר "מי אני", וכשזה התור שלו מופיע לו סימון.

## הערות

- מפתחות Firebase של אפליקציית ווב אינם סוד, והם נועדו להיות גלויים בקוד. ההגנה היא בכללי `firestore.rules`, שמאפשרים לכתוב רק רישומים בצורה שהאפליקציה יוצרת. מי שיש לו את הקישור יכול לראות ולרשום, ולכן לא מפרסמים אותו.
- בלי הגדרת Firebase האפליקציה עובדת במצב הדגמה, עם שמירה בטלפון הבודד בלבד.

## פיתוח ובדיקות

אין build. מפעילים שרת סטטי (`python3 -m http.server`) ופותחים את הדפדפן.
בדיקות ללוגיקה: `node tests/logic.test.mjs`

## מבנה

- `logic.js`: חישוב מאזן והצעת תור (בלי תלות בדפדפן)
- `store.js`: אחסון, Firebase או מצב הדגמה מקומי
- `app.js`, `index.html`, `style.css`: הממשק
- `sw.js`, `manifest.webmanifest`, `icons/`: התקנה כאפליקציה ועבודה בלי רשת
- `firestore.rules`: כללי אבטחה
